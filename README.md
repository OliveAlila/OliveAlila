# Olive Alila | Software Developer

Personal developer portfolio for Olive Alila. Built with HTML, CSS and vanilla JavaScript.

## Features
- Cinematic purple and technology-inspired visual direction
- Hybrid presentation mode: visitors can start or pause automatic scene progression
- Manual navigation, scrolling and keyboard controls
- Responsive layouts for desktop and mobile
- Reduced-motion support
- Featured projects, technical toolkit, education, training and awards

## Run locally
Open `index.html` in a browser or serve this folder with a static HTTP server.

## Publish with GitHub Pages
In repository Settings, open Pages. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Portrait image
Place Olive's approved portrait at `assets/olive-portrait.png`. The hero includes a GitHub avatar fallback until the portrait asset is uploaded.
